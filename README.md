## Классификация и оценка критичности
| № | Проблема | Категория CIA | Критичность | Обоснование |
| :--- | :---: | :---: | :---: | :--- |
| 1 | Нету HTTPS | C | Критичный | Данные передаются открыто, можно перехватить |
| 2 |  Нет SSL-сертификата | C, A | Высокий | Браузеры блокируют сайт |
| 3 | Панель /wp-admin открывается | C | Высокий | Автоматические сканеры находят и подбирают пароль |
| 4 | Нет двухфакторной аунтификации | C | Высокий | Даже при утечке пароля аккаунт не защищён |

## Рекомендации

- [ ] Включить двухфакторную аутентификацию для всех администраторов (системный администратор, 5 дней)

## Итоговая оценка
- **Общий уровень безопасности**: критический
  
**Что сделать в первую очередь**:
1. Установить SSL-сертификат и полностью перевести сайт на защищенный протокол HTTPS (устраняет проблемы №1 и №4).
2. Скрыть стандартный URL панели /wp-admin и включить защиту от автоматического подбора паролей (капчу) (устраняет проблему №2).
3. Включить обязательную двухфакторную аутентификацию для всех учетных записей администраторов (устраняет проблему №3).
